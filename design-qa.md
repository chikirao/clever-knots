## Проверенные поверхности

- **Типографика:** локальные Literata и Onest с кириллицей и латиницей. Крупное двухстрочное название и спокойный русский UI. Макетный шрифт генератора приблизительный: реальная Literata выбрана и оптически настроена, не заявляется точное совпадение glyph shapes.
- **Ритм/сетка:** мобильная композиция отдельная, CTA доступна в первом экране 390×844; desktop асимметричный. Нет overflow на пяти целевых ширинах. Поля, масштаб знака и интервал перед CTA исправлены по двум проходам.
- **Цвет:** светлая основа #F4F0E5, тёмная хвоя #213B26, натуральный коричневый канат; текст и кнопки не используют динамически меняющийся фон. Вторичный текст #655D50 на светлой основе.
- **Изображения:** настоящие четыре предоставленных фотографии одного изделия. SVG/HTML не заменяют фотографии или плетёный знак. Astro responsive WebP variants, заданные dimensions. Прозрачный знак не имеет широкого halo. Генеративные изделия и портреты не добавлялись.
- **Текст/контент:** название неизменно, цены и availability отсутствуют до подтверждения. Вместо выдуманного ассортимента одна работа с ракурсами. О мастерской содержит только исходные сведения о техниках.
- **Motion:** ClientRouter и shared image names; один GSAP ticker для каната; реальные Fluid Tabs в каталоге. Динамический reduced motion и no-WebGL fallback сохраняют весь контент.
- **Физика:** объёмные спиральные пряди, texture normal/color, matte lighting и soft shadow. Прозрачный SVG hit area отвечает за pointer capture; при захвате локальная GPU-деформация управляется пружиной, затем возвращается. Нативная прокрутка вне каната сохраняется.

## История исправлений

1. [P1] Первоначальная ribbon-модель была слишком гладкой и отличалась от растрового знака. Заменена на три настоящие helical tube meshes с depth occlusion, tangent-space микрорельефом и ворсинками. Evidence: final scroll-selected / desktop-latest.
2. [P2] Толщина и касательная на стыке не совпадали. Начало взято из измеренного хвоста изображения (89.9% / 69%), radius зависит от ширины знака, mask плавно передаёт изображение в mesh. Evidence: rope-seam / hero-390.
3. [P2] Изгиб пересекал заголовок. Маршрут проходит ниже текста и под макрофото; подпись защищена бумажной подложкой. Невидимая часть за макрофото не захватывает жесты. Evidence: scroll-detail.
4. [P1] Touch-захват отменялся браузерной прокруткой. touch-action:none перенесён на SVG-ancestor; вне области нити touch проходит к обычным элементам. Проверено реальными CDP touchStart/move/end, не только dispatchEvent.
5. [P2] После смены reduced motion обратно WebGL нельзя было получить у уже использованного 2D canvas. При повторной инициализации создаётся свежий canvas; handlers, ticker и GPU buffers очищаются. Проверка добавлена в browser suite.
6. [P1] Канат выглядел топорно: пряди-трубки расходились на изгибах, пластиковый оранжевый цвет, шов на стыке, маршрут обрезался краем экрана. Renderer заменён аналитической трёхпрядной Z-скруткой на одной ленте с параметрами, снятыми с хвоста знака. Микрофактура — high-pass хлопка с фото знака, цветное тёплое затенение, распушённый конец, петля с тенью на себя. Маршрут — сплайн по свободным полям, проверен на отсутствие наложений на текст при 360/390/430/768/1000/1100/1280/1440/1920. Browser suite и touch suite прошли, frame interval 13.3/13.5 ms.

## Проверки и ограничения

`npm run check`: 0 errors, 0 warnings; 4 upstream type deprecation hints в оригинальном Fluid Tabs. `npm run build`: успешно. CMS schema/content paths проверены; отдельный build проверил `/clever-knots/` prefix и исключение unpublished fixture из маршрутов и sitemap. Main content после теста восстановлен.

Browser suite: пять ширин, меню/Escape/focus, Fluid selected state, галерея/next/zoom/Escape, переходы/back, reduced motion, no-WebGL, mouse drag/spring, GPU context loss. Touch suite: захват, пружина и прокрутка вне нити. Артефакты: `.qa/report.json`, `.qa/rope-report.json`.

Финальная touch-проверка: тяга 43.5 px, возврат пружины подтверждён, native scroll вне каната подтверждён. В browser emulation 390×844, DPR 1.5, median/p95 frame interval 13.3/13.4 ms; при CPU throttling 4× — 13.3/13.5 ms. Это интервалы кадров данного desktop browser при скролле, не замер GPU time и не FPS настоящего телефона. Все финальные browser assertions passed, errors=[], failed=[].

На реальном телефоне FPS не измерен. Desktop browser с мобильным viewport/DPR и CPU throttling не доказывает производительность конкретного телефона. Live Pages CMS save/upload/publish требует GitHub App installation и доступа владельца; пока проверена конфигурация и build pipeline, не работа аккаунта.
