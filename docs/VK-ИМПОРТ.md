# Товары из VK на сайт: что сделать после подарка

Сайт умеет сам забирать товары из VK Маркета сообщества «Макраме Клевер» (vk.ru/market-225481050): названия, описания, цены и фото. Всё готово, не хватает только ключа доступа VK. Делается один раз, минут 15.

## Что сейчас на сайте

В каталоге 6 товаров из VK с настоящими текстами и ценами, но вместо фото стоят заглушки «Фото скоро» (`src/assets/uploads/vk/*-placeholder-*.webp`). Первый запуск импорта заменит их настоящими фотографиями и добавит остальные товары.

## Шаг 1. Ключ доступа в VK (делает мама, она администратор сообщества)

1. Открыть сообщество → «Управление».
2. «Дополнительно» → «Работа с API» → вкладка «Ключи доступа».
3. «Создать ключ», отметить галочку **«Товары»**, сохранить и подтвердить (VK пришлёт код).
4. Скопировать ключ. Это пароль к товарам сообщества: не пересылать в чаты и не вставлять в код.

Если первый запуск напишет ошибку доступа к методу `market.get`, значит VK не отдаёт товары по ключу сообщества. Тогда нужен ключ пользователя-администратора: создать приложение на dev.vk.com (тип «Standalone») и получить токен с правом `market`. Это делается вместе с Claude.

## Шаг 2. Проверка на компьютере

В PowerShell в папке проекта:

```powershell
$env:VK_TOKEN="сюда ключ"; node scripts/vk-import.mjs --dry
```

`--dry` ничего не меняет, только показывает, какие товары будут добавлены или обновлены. Если список правильный, запустить без `--dry`, затем `npm run check` и посмотреть сайт.

## Шаг 3. Автоматическая загрузка каждый день

1. Залить проект в репозиторий GitHub (сейчас он ещё не в git).
2. GitHub → репозиторий → Settings → Secrets and variables → Actions → **New repository secret**: имя `VK_TOKEN`, значение — ключ.
3. Вкладка Actions → «Импорт товаров из VK» → **Run workflow** для первого запуска.

Дальше импорт работает сам каждый день в 06:00 по Москве (`.github/workflows/vk-sync.yml`): забирает товары, проверяет, что сайт собирается, и сохраняет изменения. Публикация на GitHub Pages включается отдельно переменной `ENABLE_PAGES_DEPLOY` (см. `docs/DEPLOYMENT.md`).

## Как это работает для мамы

- **Добавила товар в VK** — на следующий день он на сайте.
- **Изменила цену, описание или фото в VK** — на сайте тоже обновится.
- **Удалила товар из VK** — на сайте он скроется, но не сотрётся.
- **В админке сайта (Pages CMS)** можно выключить показ, вынести работу на главную, поменять порядок и технику. Импорт эти настройки не перезаписывает.
- Работы, добавленные вручную через админку, импорт не трогает.

## Технически

- Скрипт: `scripts/vk-import.mjs`, официальный метод VK API `market.get`. Фото сжимаются до 1600 px в WebP.
- Связь с товаром — поле `vkId` в `src/content/works/*.json`; ссылка на товар — `vkUrl` (кнопка «Заказать в VK» на странице работы).
- Из VK обновляются: название, описание, цена, наличие, фото. Сайтом управляются: адрес, техника, показ, «на главной», порядок.
